The application uses several megabytes of flash archive; its size and the number of AppIns installer files depend on the build. Note that the TI84 CPU is an evolution of a CPU from 1976. It is much slower than a current CPU, e.g. about 10* slower than a Casio fxcg50 processor, or 100* slower than a Numworks. Be prepared to wait if you run a non trivial computation.

IMPORTANT: manually delete all installed Flash apps, including language packs, in Memory Management (2nd, +, then 2). A memory reset alone does not remove them. INST requires KhiCAS to be the first installed app because its Flash address is fixed. Back up your apps first; reinstall other apps only after installing KhiCAS.

Beware: the install program below will write in the calculator user flash. If the install program freezes the calculator, press 2nd and del, then the reset button while 2nd and del are pressed. Then press cancel to erase all the flash, transfer the OS to the calc. If you make another install try, do not use the bundle file khicas84.b84 (step 2 or b below).

======================================================================
Install tested on a 83ce with OS 5.3.0, with 3014Ko archive available
======================================================================
        1/ Backup your data, apps and lang packages, then reset archive memory (2nd mem 7 rightarrow 3), remove lang packages (2nd mem 2 1)
        2/ Transfer transfer INST, artifice and all the files in app, in this order, to the calculator. If you are using TI Connect CE on Windows, you can instead transfer https://www-fourier.univ-grenoble-alpes.fr/~parisse/ti/khicas84.b84
(this does not work under Mac OS or Chrome). If you are using tilp under linux, run the transfert_tilp.sh script (don't use the GUI)
        3/ Run INST from prgm. 
        4/ IMPORTANT: reset the RAM with 2nd mem 7 1
After install, check and remove the variables AppIns* (installation file not required anymore).
        
===================================================================
For more recent OS (5.5 or above), the process is more complicated
===================================================================
Since TI has disabled asm, we will have to run artifice (https://yvantt.github.io/arTIfiCE/).
        a/ Backup your data, apps and your language pack. Reset archive memory (2nd mem 7 rightarrow 3), remove language packs. (2nd mem 2 1)
        b/ Transfer transfer INST, artifice and all the files in app, in this order, to the calculator. If you are using TI Connect CE on Windows, you can instead transfer https://www-fourier.univ-grenoble-alpes.fr/~parisse/ti/khicas84.b84 (this does not work under Mac OS or Chrome). If you are using tilp under linux, run the transfert_tilp.sh script (don't use the GUI).
        c/ open artifice (prgmA)
        d/ run INST. This will reset the calc but not clear the RAM
        e/ IMPORTANT: clear the RAM with 2nd mem 7 1

After install, check and remove the variables AppIns* (installation file not required anymore).

===================================================
Now you can run KhiCAS from app (2nd resol on 83ce)
===================================================
Use the 5 keys just under the screen for fast menus (3 menus per key using 2nd/alpha), press the math key for a list of commands by categories.
Leave KhiCAS from the shell with 2nd, MODE (QUIT).

Native 2D editor:
With 2D history enabled, typing on an empty command line opens the editor automatically, except in Python mode. Recent history stays visible above the editor. ENTER returns the expression to the command line; press ENTER again to evaluate it. Disable MODE, "2D history" for plain command-line entry.
Press 2nd, X,T,theta,n on a TI-84 Plus CE, or the fraction template key on a TI-83 Premium CE. The current expression opens selected; MODE switches between selection and caret editing. In selection mode, left/right select siblings and up/down select the parent/child expression.
F5 (the rightmost key under the screen) evaluates the selection, or the whole expression in caret mode. ENTER accepts the edit. CLEAR undoes the last edit, then cancels when nothing remains to undo; 2nd, MODE (QUIT) discards edits immediately. 2nd, CLEAR empties the editor.
F1/F2 and MATH provide templates for fractions, integrals, sums, limits and series. Matrices are shown as grids; comma adds a column and 2nd, ENTER adds a row. The line below the 2D display shows the Giac source text.
Console history also displays expressions and results in 2D. Toggle MODE, "2D history" to use compact text instead. Copying and recalling an entry keeps its Giac source text; strings, programs and oversized expressions use text display.
Results that fit in 2D history are displayed directly without opening the expression editor for confirmation. Larger results can still use the editor.
Leaving a graph adds a thumbnail to 2D history. Recall or copy it to recover the plot command, or open it to redisplay the graph. Saved sessions keep the command and a "Graphic object" placeholder, not the thumbnail bitmap.

Interrupted calculations and low-memory handling have been improved. Recovery from memory exhaustion is best effort; save your session regularly.

OS interaction:
a/ KhiCAS can import OS Y1-Y9 and Y0 variables.
Type 2nd L1 to 2nd L6 from KhiCAS shell to get Y1 to Y6. 
This enables 2d input from OS (f(x) key, enter Y1-Y9 or Y0 then 2nd app and run KhiCAS).
b/ KhiCAS auto-saves the last evaled expression in Y2. 
You can also explicitly store an expression in Y1-Y9 or Y0 by appending =>Yk (shortcut sto key followed by 2nd L1 to 2nd L6).
c/ KhiCAS can import TI matrices. Press stats, select matrix, type enter. This will import the given matrix and save it with the same lowercase name.

Caveat: there are probably bugs remaining, that might cause crash and reset. If you enter an infinite loop of memory error while leaving KhiCAS, press and keep reset pressed 3-4 seconds to clear the RAM. If that does not work, keep 2nd+trace pressed as well as reset (this will flash the screen and clear the ram. Another shortcut is reset+2nd+del to be able to flash the calc and send the OS again).
